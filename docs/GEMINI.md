# Gemini Code-Assist Configuration for /docs

This directory contains all project documentation.

## Directory Structure

-   `api/`: Documentation related to the public-facing APIs, including quick start guides and examples.
-   `dev/`: Developer-focused documentation, covering architecture, best practices, and internal systems.
-   `module/`: Detailed documentation for each business module (e.g., Inventory, Finance).

## Guidelines

-   Keep documentation concise and up-to-date.
-   When adding a new feature, create or update the relevant documentation in the appropriate subdirectory.
-   Use Markdown for all documentation files.
