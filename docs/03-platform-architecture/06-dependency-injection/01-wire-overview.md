# Wire Dependency Injection

## Why Wire

AwoERP uses Google Wire for compile-time dependency injection. Wire generates `wire_gen.go` — a plain Go file that wires all constructors together. No reflection, no runtime magic, no startup overhead.

Benefits:
- **Compile-time safety**: missing providers are caught at `wire` generation, not at runtime
- **Readable output**: `wire_gen.go` is readable Go — the full wiring is explicit
- **No runtime cost**: DI is resolved at compile time

## Concepts

### Provider

A function that constructs a type from its dependencies:

```go
// Provider function
func NewContractService(
    repo repository.ContractRepository,
    authzSvc iam.AuthzService,
    log zerolog.Logger,
) ContractService {
    return &contractService{repo: repo, authzSvc: authzSvc, log: log}
}
```

### ProviderSet

A named collection of providers for a module:

```go
var ProviderSet = wire.NewSet(
    NewContractRepository,
    NewContractService,
    NewContractHandler,
    NewContractRouteRegistrar,
    wire.Bind(new(ContractService), new(*contractService)),
)
```

### Injector

The top-level function that Wire generates code for:

```go
//go:build wireinject

func InitializeApp(cfg Config) (*server.App, error) {
    wire.Build(
        db.ProviderSet,
        iam.ProviderSet,
        contracts.ProviderSet,
        server.ProviderSet,
    )
    return nil, nil
}
```

## wire_gen.go

Wire generates the actual wiring code. It is committed to the repo and must never be edited manually:

```go
// Code generated by Wire. DO NOT EDIT.
func InitializeApp(cfg Config) (*server.App, error) {
    pool, err := db.NewPool(cfg.DB)
    if err != nil {
        return nil, err
    }
    store := db.NewStore(pool)
    contractRepo := repository.NewContractRepository(store)
    // ... etc.
}
```

## Regenerating Wire

After any provider change:

```bash
make wire
# equivalent to: cd cmd/server && wire
```

Commit both the changed provider file and the updated `wire_gen.go`.

## Common Wire Errors

| Error | Cause | Fix |
|-------|-------|-----|
| `missing provider for X` | No provider registered for type X | Add provider or ProviderSet |
| `has multiple providers for X` | Two providers return same type | Use `wire.Bind` or rename types |
| `cycle detected` | A → B → A dependency | Refactor to break cycle |
| `provider X is not reachable` | Provider included but nothing needs it | Remove from ProviderSet |
