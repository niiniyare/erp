# Volume XI — amis Web Renderer

Volume XI documents the integration of the Baidu **amis** low-code framework as AwoERP's primary web rendering engine. It covers everything from the bootstrap `index.html` entry point — including every `<meta>` tag, CSS load order, `window.__AWO_BOOTSTRAP__` inline data block, and `amis.embed()` environment configuration — through the `app` component shell variants (staff ERP, supplier portal, customer portal, employee self-service), the full renderer runtime lifecycle, and the governance rules that keep the component layer clean and maintainable across all tenant surfaces.

Engineers who are building new UI surfaces should read Volume II (DSL & AST) and Volume III (Component System) first to understand how surfaces are defined. This volume is the companion reference for **how those surfaces are mounted and rendered** in the browser: how the amis SDK is loaded, how tenant and portal context is injected, how the navigation API payload is wired into the `app` shell, and how the SSE channel is opened on surface mount. It also documents the approved amis component list, banned components, and the 60-line screen file rule enforced by CI.

Volume XI relates closely to Volume IV — Rendering Architecture (Chapter 18 covers web rendering broadly; Chapter 19-B covers backend-driven navigation consumed by the amis `app` component) and Volume VI — Platform & API (Chapter 25-B covers the `env.fetcher` custom fetch wrapper and `requestAdaptor`/`responseAdaptor` patterns that every amis API call passes through). Read this volume alongside those chapters for a complete picture of the AwoERP web rendering stack.
