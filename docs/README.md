# AWO ERP Documentation Server

This directory contains a Go-based web server that serves the comprehensive AWO ERP documentation, including both MkDocs-generated developer documentation and SchemaSpy-generated database schema documentation.

## 🏗️ Architecture

The documentation server serves content from two main sources:

```
docs/
├── main.go                 # Go web server
├── start-docs.sh          # Production startup script  
├── test-server.sh         # Testing script
├── index.html            # Landing page with navigation (MkDocs-safe)
├── schema/               # SchemaSpy database documentation
│   ├── index.html
│   ├── tables/
│   ├── diagrams/
│   └── ...
└── ../site/              # MkDocs generated documentation (no custom index.html)
    ├── getting-started/
    ├── reference/
    └── ...
```

## 🚀 Quick Start

### Option 1: Using the startup script (Recommended)
```bash
cd docs/
./start-docs.sh [port]
```

### Option 2: Direct Go execution
```bash
cd docs/
go run main.go --port 8081
```

### Option 3: Using environment variable
```bash
export DOC_PORT=8081
cd docs/
./start-docs.sh
```

## 📡 Endpoints

| Endpoint | Description | Source |
|----------|-------------|---------|
| `/` | Landing page with navigation | `docs/index.html` |
| `/getting-started/...` | Developer documentation | `../site/` (MkDocs) |
| `/reference/...` | API reference | `../site/` (MkDocs) |
| `/contributing/...` | Contributing guides | `../site/` (MkDocs) |
| `/schema/` | Database schema documentation | `docs/schema/` (SchemaSpy) |
| `/schema/tables/...` | Individual table documentation | `docs/schema/tables/` |
| `/schema/diagrams/...` | ER diagrams | `docs/schema/diagrams/` |

## 🏭 Content Generation

### MkDocs Documentation
The main documentation is generated using MkDocs from the project root:

```bash
# Install MkDocs and dependencies
pip install mkdocs mkdocs-material

# Generate documentation
mkdocs build

# This creates the ../site/ directory with HTML files
```

### Database Schema Documentation  
The database schema documentation is generated using SchemaSpy:

```bash
# Generate schema documentation
java -jar schemaspy.jar \
  -t pgsql \
  -host localhost \
  -port 5432 \
  -db your_database \
  -u your_username \
  -p your_password \
  -o docs/schema
```

## 📁 File Structure Details

### Go Server (`main.go`)
- **Route `/`**: Serves custom landing page from `docs/index.html` (MkDocs-safe)
- **Route `/*`**: Serves MkDocs content from `../site/`
- **Route `/schema/`**: Serves SchemaSpy content from `./schema/`
- **Auto-index**: Automatically serves `index.html` for directories
- **Static files**: Properly handles CSS, JS, images, and other assets
- **MkDocs Compatible**: Won't be overwritten by `mkdocs build`

### Landing Page (`index.html`)
- Modern, responsive design
- Navigation to both documentation types
- Auto-redirect to getting started guide
- Visual indicators and countdown timer

### Schema Documentation (`schema/`)
Generated by SchemaSpy, includes:
- Interactive table documentation
- Entity relationship diagrams  
- Data dictionary
- Constraint information
- Index details

## 🐛 Troubleshooting

### Common Issues

1. **"../site/ directory not found"**
   ```bash
   # Solution: Generate MkDocs documentation
   cd .. && mkdocs build
   ```

2. **"./schema/ directory not found"**  
   ```bash
   # Solution: Generate SchemaSpy documentation
   java -jar schemaspy.jar [options] -o docs/schema
   ```

3. **Port already in use**
   ```bash
   # Solution: Use different port
   ./start-docs.sh 8082
   ```

4. **CSS/JS assets not loading**
   - Check that both `../site/assets/` and `./schema/` directories exist
   - Verify file permissions are readable
   - Check browser console for specific error messages

### Debug Mode
For debugging, you can run the server directly:
```bash
go run main.go --port 8081
```

This will show detailed request logs and error messages.

## 🔄 Development Workflow

1. **Update documentation source files**
2. **Regenerate static content:**
   ```bash
   # For MkDocs (safe - won't overwrite docs/index.html)
   mkdocs build
   
   # For SchemaSpy (when database changes)
   java -jar schemaspy.jar [options] -o docs/schema
   ```
3. **Test the server:**
   ```bash
   ./test-server.sh
   ```
4. **Deploy/restart the documentation server**

### 📝 MkDocs Integration Notes

- **Landing Page Protected**: `docs/index.html` is served for `/` and won't be overwritten by `mkdocs build`
- **MkDocs Content**: All MkDocs pages are served normally from `/getting-started/`, `/reference/`, etc.
- **No Conflicts**: You can run `mkdocs build` safely without losing the custom navigation
- **Custom Branding**: The landing page provides unified access to both documentation types
