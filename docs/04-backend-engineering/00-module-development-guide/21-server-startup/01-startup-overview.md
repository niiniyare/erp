# Server Startup Overview

The server entry point is `cmd/server/main.go`. Startup follows a strict sequence: configuration load → dependency injection → pre-flight checks → worker start → HTTP server.

## Startup Sequence

```
1. Load config (env vars, config file)
2. Initialize logger (zerolog)
3. Initialize tracer (OpenTelemetry)
4. Initialize metrics (Prometheus)
5. Connect to PostgreSQL (pgxpool)
6. Run database migrations (up to latest)
7. Initialize Redis (session store, cache)
8. Initialize Temporal client
9. Wire.InitializeApp() — builds full DI graph
10. Register event subscriptions
11. Register Temporal schedules
12. Start Temporal workers (goroutines)
13. Start health probe server (separate port)
14. Start Fiber HTTP server (blocking)
15. On signal: graceful shutdown
```

## Package Layout

```
cmd/
└── server/
    ├── main.go              # entry point, shutdown orchestration
    ├── config.go            # Config struct, env parsing
    └── wire_gen.go          # auto-generated by Wire (never edit)

internal/
├── server/
│   ├── app.go               # App struct holding all initialized deps
│   ├── setup.go             # setupFiber(), registerRoutes()
│   └── health.go            # /health/live, /health/ready handlers
└── platform/
    ├── db/                  # pgxpool provider
    ├── redis/               # redis client provider
    └── temporal/            # temporal client provider
```

## Graceful Shutdown

The server listens for `SIGINT` and `SIGTERM`. On signal:

1. Stop accepting new HTTP connections
2. Wait for in-flight requests (up to 30 seconds)
3. Stop Temporal workers
4. Close database pool
5. Flush trace/metric exporters
6. Exit 0

```go
// cmd/server/main.go
quit := make(chan os.Signal, 1)
signal.Notify(quit, os.Interrupt, syscall.SIGTERM)
<-quit

log.Info().Msg("shutting down gracefully")

ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()

if err := fiberApp.ShutdownWithContext(ctx); err != nil {
    log.Error().Err(err).Msg("graceful shutdown failed")
}

for _, w := range temporalWorkers {
    w.Stop()
}

dbPool.Close()
tracerProvider.Shutdown(ctx)
```
