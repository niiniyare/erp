## I18n Responsibility Distribution

### 1. **Builder** (Design-Time) 
**Defines what needs translation**

```go
// Builder marks translatable content
field := &Field{
    Name: "first_name",
    Label: "First Name",           // Translatable
    Placeholder: "Enter first name", // Translatable
    HelpText: "Your legal first name", // Translatable
    I18nKey: "fields.first_name",    // Translation key
}
```

**Responsibilities:**
- Mark which fields need translation
- Assign translation keys
- Define default language content

---

### 2. **Registry** (Storage)
**Stores translations**

```go
// Registry stores translations alongside schemas
type SchemaWithTranslations struct {
    Schema       *Schema
    Translations map[string]Translation // locale -> translation
}

type Translation struct {
    Locale string
    Fields map[string]FieldTranslation
}

type FieldTranslation struct {
    Label       string
    Placeholder string
    HelpText    string
    ErrorMessages map[string]string // validation errors
}
```

**Responsibilities:**
- Store translations for multiple locales
- Provide translation retrieval by locale
- Version translations with schemas

---

### 3. **Enricher** (Context Injection) ⭐ **PRIMARY OWNER**
**Applies user's locale translations**

```go
// Enricher injects locale-specific content
func (e *Enricher) applyLocalization(
    ctx context.Context,
    schema *Schema,
    user *User,
) error {
    locale := user.PreferredLanguage // e.g., "en-US", "fr-FR", "es-ES"
    
    // Get translations for this locale
    translations, err := e.registry.GetTranslations(schema.ID, locale)
    if err != nil {
        // Fallback to default locale
        translations, _ = e.registry.GetTranslations(schema.ID, "en-US")
    }
    
    // Apply translations to each field
    for i := range schema.Fields {
        field := &schema.Fields[i]
        
        if trans, exists := translations.Fields[field.Name]; exists {
            field.Label = trans.Label
            field.Placeholder = trans.Placeholder
            field.HelpText = trans.HelpText
            
            // Apply localized validation messages
            for j := range field.Validations {
                rule := &field.Validations[j]
                if msg, ok := trans.ErrorMessages[rule.Type]; ok {
                    rule.Message = msg
                }
            }
        }
    }
    
    return nil
}
```

**Responsibilities:** ⭐
- Detect user's locale (from user profile, browser, or request header)
- Load appropriate translations
- Replace default text with localized versions
- Handle fallback locales
- Apply locale-specific formatting (dates, numbers, currency)

---

### 4. **Runtime** (Execution)
**Handles dynamic locale switching**

```go
// Runtime can switch locale on-the-fly
func (r *Runtime) SwitchLocale(ctx context.Context, newLocale string) error {
    // Re-enrich schema with new locale
    user := &User{PreferredLanguage: newLocale}
    enriched, err := r.enricher.Enrich(ctx, r.schema.Clone(), user)
    if err != nil {
        return err
    }
    
    r.schema = enriched
    return nil
}
```

**Responsibilities:**
- Support dynamic locale switching
- Format values according to locale (dates, numbers)
- Handle RTL (right-to-left) languages if needed

---

### 5. **Renderer** (Display)
**Renders localized content**

```go
// Renderer displays the translated text
func (r *Renderer) RenderField(field *Field) string {
    // By this point, field.Label is already translated
    return fmt.Sprintf(`
        <label>%s</label>
        <input placeholder="%s" />
        <small>%s</small>
    `, field.Label, field.Placeholder, field.HelpText)
}
```

**Responsibilities:**
- Display already-translated content
- Apply locale-specific formatting
- Handle text direction (LTR/RTL)

## Recommended Architecture

### **Enricher is the Primary Owner** ⭐

The **Enricher** should handle I18n because:

1. ✅ It already injects user context
2. ✅ It runs before rendering (perfect timing)
3. ✅ Can access user's locale preference
4. ✅ Can handle fallback logic
5. ✅ Keeps renderer simple (just display, no logic)

### Complete I18n Flow

```
User Request (locale: "es-ES")
        ↓
Registry → Load schema + translations
        ↓
Enricher → Apply Spanish translations
        ↓
Runtime → Manage state with localized text
        ↓
Renderer → Display Spanish UI
```

### 2. Enricher Applies Translations

```go
// Enhanced enricher with I18n
func (e *Enricher) EnrichWithOptions(
    ctx context.Context,
    schema *Schema,
    opts *EnrichOptions,
) (*EnrichmentResult, error) {
    // ... other enrichment steps
    
    // Determine locale
    locale := e.getLocale(opts.User, ctx)
    
    // Apply localization
    if err := e.applyLocalization(ctx, schema, locale); err != nil {
        log.Error().Err(err).Msg("Failed to apply localization")
        // Don't fail enrichment, just log
    }
    
    // Apply locale-specific formatting
    if err := e.applyLocaleFormatting(schema, locale); err != nil {
        log.Error().Err(err).Msg("Failed to apply locale formatting")
    }
    
    return result, nil
}

func (e *Enricher) getLocale(user *User, ctx context.Context) string {
    // Priority order:
    // 1. User preference
    if user != nil && user.PreferredLanguage != "" {
        return user.PreferredLanguage
    }
    
    // 2. Request header (Accept-Language)
    if locale := getLocaleFromContext(ctx); locale != "" {
        return locale
    }
    
    // 3. Default
    return "en-US"
}

func (e *Enricher) applyLocaleFormatting(schema *Schema, locale string) error {
    // Set locale-specific formats
    for i := range schema.Fields {
        field := &schema.Fields[i]
        
        switch field.Type {
        case "date":
            field.Format = getDateFormat(locale)
        case "currency":
            field.Format = getCurrencyFormat(locale)
        case "number":
            field.Format = getNumberFormat(locale)
        }
    }
    
    return nil
}

func getDateFormat(locale string) string {
    formats := map[string]string{
        "en-US": "MM/DD/YYYY",
        "en-GB": "DD/MM/YYYY",
        "es-ES": "DD/MM/YYYY",
        "fr-FR": "DD/MM/YYYY",
        "de-DE": "DD.MM.YYYY",
        "ja-JP": "YYYY/MM/DD",
    }
    
    if format, exists := formats[locale]; exists {
        return format
    }
    
    return "YYYY-MM-DD" // ISO default
}
```

### 3. Handler with Locale Detection

```go
func HandleFormWithLocale(c *fiber.Ctx) error {
    // Get user
    user := GetUserFromContext(c)
    
    // Detect locale from:
    // 1. Query param: ?locale=es-ES
    // 2. User preference
    // 3. Accept-Language header
    locale := c.Query("locale")
    if locale == "" && user != nil {
        locale = user.PreferredLanguage
    }
    if locale == "" {
        locale = parseAcceptLanguage(c.Get("Accept-Language"))
    }
    if locale == "" {
        locale = "en-US" // default
    }
    
    // Override user locale for enrichment
    userWithLocale := user
    if userWithLocale != nil {
        userWithLocale.PreferredLanguage = locale
    }
    
    // Load and enrich with locale
    schema, _ := registry.Get(c.Context(), "invoice-form")
    enriched, _ := enricher.Enrich(c.Context(), schema.Clone(), userWithLocale)
    
    return views.FormPage(enriched, nil).Render(
        c.Context(),
        c.Response().BodyWriter(),
    )
}

func parseAcceptLanguage(header string) string {
    // Parse "Accept-Language: en-US,en;q=0.9,es;q=0.8"
    if header == "" {
        return ""
    }
    
    parts := strings.Split(header, ",")
    if len(parts) > 0 {
        locale := strings.Split(parts[0], ";")[0]
        return strings.TrimSpace(locale)
    }
    
    return ""
}
```

```go
// POST /api/forms/:id/locale
func HandleLocaleSwitch(c *fiber.Ctx) error {
    var payload struct {
        Locale string `json:"locale"`
    }
    if err := c.BodyParser(&payload); err != nil {
        return err
    }
    
    // Get runtime
    rt := getOrCreateRuntime(c, schema)
    
    // Switch locale
    if err := rt.SwitchLocale(c.Context(), payload.Locale); err != nil {
        return c.Status(500).JSON(fiber.Map{"error": "Failed to switch locale"})
    }
    
    // Return localized schema
    return c.JSON(rt.schema)
}
```

```go
type PluralTranslation struct {
    Zero  string `json:"zero"`
    One   string `json:"one"`
    Few   string `json:"few"`
    Many  string `json:"many"`
    Other string `json:"other"`
}

func getPlural(count int, translations PluralTranslation, locale string) string {
    // English rules
    if locale == "en-US" {
        if count == 0 {
            return translations.Zero
        }
        if count == 1 {
            return translations.One
        }
        return translations.Other
    }
    
    // Add more locale-specific plural rules
    return translations.Other
}

// Usage
validation := ValidationRule{
    Message: getPlural(5, PluralTranslation{
        Zero:  "No items selected",
        One:   "1 item selected",
        Other: "%d items selected",
    }, locale),
}
```

### Interpolation

```go
// Translation with variables
translations := map[string]string{
    "welcome_message": "Welcome, {{name}}!",
    "items_remaining": "You have {{count}} items remaining",
}

func interpolate(template string, vars map[string]interface{}) string {
    result := template
    for key, value := range vars {
        placeholder := fmt.Sprintf("{{%s}}", key)
        result = strings.ReplaceAll(result, placeholder, fmt.Sprintf("%v", value))
    }
    return result
}

// Usage
message := interpolate(translations["welcome_message"], map[string]interface{}{
    "name": user.Name,
})
```

## Summary

### **Who Handles I18n:**

| Component | Responsibility | Level |
|-----------|---------------|-------|
| **Builder** | Define translation keys | Define |
| **Registry** | Store translations | Store |
| **Enricher** ⭐ | Apply user's locale | **Primary** |
| **Runtime** | Handle locale switching | Support |
| **Renderer** | Display translated content | Display |

### **The Enricher is the primary owner** because it:
- Has access to user context (locale preference)
- Runs at the right time (before rendering)
- Can handle fallback logic
- Keeps other components simple

This separation of concerns ensures clean architecture while providing flexible internationalization support!
