♿ Accessibility Enhancements

Focus Management

/* All interactive elements now have focus-visible styles */ .erp-btn:focus-visible { outline: 3px solid var(--service-focus); outline-offset: 2px; }

Reduced Motion Support

/* Automatically respects user's motion preferences */ @media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }

Touch Targets

/* All buttons meet 44px minimum touch target */ .erp-btn { min-height: var(--touch-target-min); /* 44px */ }

Screen Reader Support

<!-- Screen reader only text --> <span class="erp-sr-only"> Close dialog </span> <!-- Skip to content link --> <a href="#main" class="erp-skip-link"> Skip to main content </a>

🚀 Migration Guide (v1.0 → v2.0)

Step 1: Update CSS File

Replace your v1.0 CSS file with v2.0. All existing classes will continue to work.

<!-- Before --> <link rel="stylesheet" href="erp-theme-v1.css"> <!-- After --> <link rel="stylesheet" href="erp-theme-v2.css">

Step 2: No Breaking Changes!

✅ Your existing HTML markup works without any changes

✅ All v1.0 classes are fully supported

✅ Theme switching continues to work the same way

Step 3: Adopt New Features Gradually

Start using new features as needed:

/* Use new CSS variables in your custom styles */ .my-component { padding: var(--space-lg); gap: var(--space-md); font-size: var(--font-size-sm); }

Step 4: Enhance Accessibility

<!-- Add aria labels to buttons --> <button class="erp-btn-icon-only" aria-label="Close"> × </button> <!-- Use semantic HTML --> <nav aria-label="Main navigation"> <!-- navigation content --> </nav>

💡 Best Practices

Use CSS Variables

Always use variables instead of hardcoded values for consistency

Theme-Aware Styling

Components automatically adapt to the active theme (Console, Workspace, Portal)

Semantic Classes

Use semantic class names (.error, .success) instead of color-based ones

Accessibility First

Always include ARIA labels and ensure keyboard navigation works

Mobile Responsive

Test on mobile devices - all touch targets are 44px minimum

Performance

Use will-change sparingly and respect reduced-motion preferences

⚡ Performance Tips

Optimize Mobile Experience

/* Disable backdrop-filter on mobile for better performance */ @media (max-width: 768px) { .erp-modal-backdrop { backdrop-filter: none; } }

Use will-change Wisely

/* Only on hover/interaction, not constantly */ .erp-btn:hover { will-change: transform, box-shadow; }

Lazy Load Animations

/* Apply animations only when elements are in viewport */ <div class="animate-fade-in" data-observe="true"> Content appears when scrolled into view </div>

🎭 Theme Switching

How It Works

Each service has its own color palette and visual identity:

🖥️ Console Theme

Blue - Professional and trustworthy

Best for: Admin panels, system configuration, technical interfaces

💼 Workspace Theme

Green - Productive and efficient

Best for: Task management, collaboration tools, productivity apps

🌐 Portal Theme

Purple - Welcoming and engaging

Best for: Customer portals, public-facing apps, user dashboards

Implementation

/* Add theme class to body or root element */ <body class="console-theme"> <!-- All components use Console theme colors --> </body> /* Or use JavaScript to switch themes */ function switchTheme(theme) { document.body.className = theme + '-theme'; }
