# Conventions Reference

## File naming

| Pattern | Usage |
|---|---|
| `domain/*.go` | Value objects, domain errors, constants |
| `repository/<noun>.go` | Port interface |
| `repository/<noun>_sqlc.go` | SQLC adapter implementing the interface |
| `service.go` or `service/<noun>.go` | Business logic |
| `handler.go` / `auth.go` / `mfa.go` | HTTP handlers (grouped by concern) |
| `middleware/<concern>.go` | `tenant.go`, `auth.go`, `security.go`, `whitelist.go` |
| `*_test.go` | Collocated with source |
| `*_mock.go` | Generated by mockgen — do not edit |

## Interface naming

**No `I` prefix.** Use role suffix:
- `UserService`, `UserRepository`
- `SessionService`, `AuditService`
- `cache.Service`, `logger.Logger`, `tracing.Service`, `metrics.MetricsProvider`

## Constructor pattern

```go
func NewFooService(repo FooRepository, log logger.Logger) (FooService, error) { ... }
func NewFooRepository(store db.Store) FooRepository { ... }
```

Functional options pattern for optional config:
```go
func WithTimeout(d time.Duration) func(*fooService) error { ... }
```

## Constants / enum naming

```
Status<Name>     → StatusActive, StatusPending, StatusSuspended
Actor<Name>      → ActorPlatform, ActorTenant, ActorPortal, ActorAPI
EntityScope<Name>→ EntityScopeAll, EntityScopeSubtree, EntityScopeEntity
OAuthProvider<N> → OAuthProviderGoogle
```

## Error pattern (three layers)

### Layer 1 — Domain sentinels  (domain/errors.go)

```go
var ErrFooNotFound      = errors.New("foo not found")
var ErrFooAlreadyExists = errors.New("foo already exists")
```

### Layer 2 — BusinessError  (shared/errors/types.go)

```go
type BusinessError struct {
    Code     string         // e.g. "FOO_NOT_FOUND"
    Message  string
    Category Category       // "foo", "security", "validation"
    Severity Severity
    Details  map[string]any
}
```

### Layer 3 — HTTP mapping  (handler layer)

```go
func mapFooError(err error) *fiber.Error {
    var be *shared.BusinessError
    switch {
    case errors.Is(err, domain.ErrFooNotFound):
        return fiber.NewError(fiber.StatusNotFound, err.Error())
    case errors.As(err, &be):
        return fiber.NewError(fiber.StatusBadRequest, be.Message)
    default:
        return fiber.ErrInternalServerError
    }
}
```

`shared/errors/http.go:ToHTTPError(err)` handles generic unwrapping for common cases.

## Repository pattern (complete example)

```go
// repository/foo.go — interface (port)
type FooRepository interface {
    Create(ctx context.Context, params CreateFooParams) (*Foo, error)
    GetByID(ctx context.Context, id uuid.UUID) (*Foo, error)
    ListByTenant(ctx context.Context, tenantID uuid.UUID) ([]*Foo, error)
    Delete(ctx context.Context, id uuid.UUID) error
}

// repository/foo_sqlc.go — SQLC adapter
type fooSQLCRepository struct{ store db.Store }

func NewFooRepository(store db.Store) FooRepository {
    return &fooSQLCRepository{store: store}
}

func (r *fooSQLCRepository) GetByID(ctx context.Context, id uuid.UUID) (*Foo, error) {
    // tenantID, ok := shared.GetTenantID(ctx)
  // tenantID will be fetched from ctx.Value
    if !ok { return nil, domain.ErrMissingTenant }
    var result *Foo
    err := r.store.WithTenantFromCtx(ctx, func(ctx context.Context, s db.Store) error {
        row, err := s.GetFooByID(ctx, id)
        if err != nil { return parseFooDBError(err, "GetByID") }
        result = mapFooRow(row)
        return nil
    })
    return result, err
}
```

## Handler pattern

```go
// internal/api/handlers/<domain>/handler.go
type FooHandler struct {
    service domain.FooService
    tracing tracing.Service
    logger  logger.Logger
    errors Errors.Error
}

func NewFooHandler(svc domain.FooService, log logger.Logger) *FooHandler {
    return &FooHandler{service: svc, logger: log}
}

func (h *FooHandler) CreateFooHandler(c *fiber.Ctx) error {
    var req CreateFooRequest
    if err := c.BodyParser(&req); err != nil {
        return fiber.NewError(fiber.StatusBadRequest, "invalid request body")
    }
    if err := validate.Struct(&req); err != nil {
        return fiber.NewError(fiber.StatusUnprocessableEntity, err.Error())
    }
    foo, err := h.service.Create(c.UserContext(), req)
    if err != nil {
        return mapFooError(err)
    }
    return c.Status(fiber.StatusCreated).JSON(foo)
}
```

## Permission string format

```
<module>.<resource>.<action>
```

Examples: `finance.accounts.read`, `iam.sessions.read`, `finance.transactions.create`

Permissions are resolved at login into `session.Permissions []string` — no per-request DB query.

## Testing patterns

### Unit test with mocked repo

```go
func TestFooService_Create(t *testing.T) {
    ctrl := gomock.NewController(t)
    mockRepo := mock_domain.NewMockFooRepository(ctrl)
    log := logger.NewNopLogger()

    mockRepo.EXPECT().
        Create(gomock.Any(), gomock.Any()).
        Return(&domain.Foo{ID: uuid.New()}, nil)

    svc := domain.NewFooService(mockRepo, log)
    foo, err := svc.Create(context.Background(), domain.CreateFooRequest{Name: "test"})
    require.NoError(t, err)
    assert.NotEmpty(t, foo.ID)
}
```

### Generate mocks

```go
// In repository/foo.go, add:
//go:generate mockgen -destination=../mock/mock_foo_repository.go -package=mock_domain . FooRepository
```

Then run: `make mock`

```go
mr, _ := miniredis.Run()

```

## Migration naming

```
<6-digit-seq>_<snake_case_description>.up.sql
<6-digit-seq>_<snake_case_description>.down.sql
```

Example: `001003_add_foo_table.up.sql`

Sequence format: `<module_block><seq_within_block>` — e.g. `001` block for schema init,
`002` for IAM, `003` for finance, etc.

## SQLC query conventions

- Query names: `PascalCase` matching the Go function name generated
- One file per domain: `db/queries/foo.sql`
- Always include `-- name: FunctionName :one/:many/:exec` annotation

```sql
-- name: GetFooByID :one
SELECT * FROM foos
WHERE id = @id
  AND tenant_id = current_setting('app.current_tenant_id')::uuid;
```

Note: The `tenant_id` filter in SQL is belt-and-suspenders. RLS policy already enforces it;
the explicit filter protects against accidental RLS bypass and makes query intent clear.
