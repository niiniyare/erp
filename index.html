Architecture

Zero frontend work
to add any new
document type.

A Go backend developer can add a new form, list view, or workflow in minutes — without a single React sprint, design handoff, or frontend deployment.

01
Write a JSON schema on the backend
Define fields, validations, relationships and actions as a structured file. No HTML, no CSS, no TypeScript.
02
Baidu amis renders the interface
The Go/Fiber server serves the schema to the amis engine. Forms, lists, filters and action buttons appear instantly.
03
Permissions resolve per tenant
A typed Permissions struct seeds every page. visibleOn expressions gate fields without extra API calls.
04
CSS theming injected server-side
Multi-tenant branding at the Go layer — one codebase, per-dealer white-labelling across East Africa.
