    Authentication API Reference

    Overview

    Complete reference for authentication endpoints including login, token refresh, and session management.

    Endpoints

    POST /auth/login

    Authenticate user and return JWT token.

    Request Body: 

    {
  "username": "string",
  "password": "string",
  "tenant_id": "string"
}

    Response: 

    {
  "access_token": "string",
  "refresh_token": "string", 
  "expires_in": 3600,
  "user": {
    "id": "string",
    "username": "string",
    "roles": ["string"]
  }
}
